INSTALL MEDISTOCK

Install MEDISTOCK as a standalone desktop window:

  • Chrome / Edge (Desktop): Click the install icon in the address bar, or open Menu → Save and Share / Apps → Install MEDISTOCK.
  • Android Chrome: Tap the browser menu (⋮) → Add to Home screen / Install app.
  • iOS Safari: Tap Share → Add to Home Screen.

Note: Because MEDISTOCK runs from a single standalone index.html file without a separate service-worker file, browsers require HTTPS or localhost for the native install prompt. Opening directly via file:// still works with full localStorage persistence.
